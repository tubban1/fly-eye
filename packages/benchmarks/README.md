# @flyeye/benchmarks

Reference vectors for validating FlyEye data/runtime compatibility.

The benchmarks do not claim biological ground truth. They protect software contracts:

- idle input remains calm
- strong looming recruits the declared modeled pathway
- reset clears modeled state
- neuron-level manifest and binary counts agree
- graph indices remain in range

Use this package in CI when implementing FlyEye profiles in another language or runtime.
