# @flyeye/escape-neuron-v1

Compact neuron-level escape-pathway asset derived from the pinned MaleCNS graph.

## Contents

- LC4 / looming seed neurons
- selected strong direct escape descending-neuron targets
- turn / flight outputs
- neurons on directed seed-to-output paths up to 3 hops
- all signed internal edges among retained neurons
- remapped local indices
- original 70K indices
- MaleCNS body IDs
- provenance and source graph hash

Generated assets:

- /data/escape-neuron-v1/manifest.json
- /data/escape-neuron-v1/graph.bin
- /data/escape-neuron-v1/report.json

## Scientific boundary

The retained edges are real signed edges from the pinned MaleCNS-derived source graph. The selection is task-specific. This package does not imply any particular neural-dynamics model.
