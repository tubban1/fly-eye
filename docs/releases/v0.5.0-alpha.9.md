# FlyEye v0.5.0-alpha.9 — Publication & Citation Release

This release packages the FlyEye Developer Kit for external reuse, citation, and registry publication.

## What changed since alpha.8

- added root MIT license for FlyEye software;
- added separate MaleCNS-derived data licensing and attribution guidance;
- added `CITATION.cff`;
- added Zenodo metadata;
- published GitHub Release assets with SHA256 checksums;
- prepared npm package metadata for the five JavaScript packages;
- added npm bootstrap and OIDC trusted-publishing workflows;
- added PyPI trusted-publishing workflow for `flyeye-graphs`;
- added Hugging Face dataset card and publication pipeline;
- kept the real `flyeye.escape-neuron.v1` asset unchanged:
  - 3,376 neurons
  - 78,797 signed edges
  - 959,092 bytes

## Registry status at release time

- GitHub Release: published
- PyPI: publication workflow completed successfully
- npm: package bootstrap pending organization/scope authorization
- Hugging Face: dataset assets ready; upload pending write-capable publication path
- Zenodo: repository integration enabled; this release is intended to be the first post-enable archival trigger

## Scientific boundary

MaleCNS-derived connectivity data and FlyEye modeled dynamics remain explicitly separated.
